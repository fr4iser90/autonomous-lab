================================================================
DOMAIN APPENDIX — GAME
================================================================

Paste after a role prompt when IDEA.DOMAIN=game.

Defaults for Autonomous Lab games:
- Client-only, Pages-playable, Vite.
- Prefer **DOM**, **Canvas2D**, or **Three.js kits/PCG** (see MODEL_STACKS.md).
- Tracking: PROGRESS / CONTENT / FEATURES / SOAK / BUGS / DEMO.
- Visual ACCEPT uses `read_image` on Playwright PNGs (not file size).
- Saves: localStorage/IndexedDB profiles from the overnight template family
  (settings-only / full-save / world-save) — pick one in Arch.
- FORBIDDEN unless IDEA overrides: multiplayer server, cloud auth, UE/Unity.

Game Feature slices should move a **playable fantasy** (move, fight, build,
prestige, …) — not docs-only cycles.
