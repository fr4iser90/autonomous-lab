# Lab (machine)

Everything here is **boilerplate for the autonomy sandbox** — not the current
game. Agents: treat `lab/**` as **BOILERPLATE_OWNED** (read; do not rewrite on
`agent/*`).

| Path | What |
|------|------|
| `AGENTS.md` | Branch model, ownership, definition of done |
| `BOILERPLATE.md` | Allow/deny paths, conflict rules |
| `SETUP.md` | Host harness / hardware / prompt routing |
| `MODEL_STACKS.md` | Model × engine catalog |
| `roles/` | Agent role laws (concept / arch / feature / fix / validate / followup) |
| `examples/` | Templates + optional genre packs (**2 files/game**: Initial + Followup) |

**Root** of the repo = the live experiment (`src/`, run docs, Pages app).
